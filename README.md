# AJAMI-AI V1.0.0

Persian-first Android AI assistant for online and offline workflows.

## Project goals
- Persian chat with configurable online API
- Offline inference through a locally installed/downloaded model runtime
- Conversation history and settings
- Modular assistants for coding, translation, medical information, image/audio/video workflows, and weather
- Local media/model management

## Important implementation policy
A feature is marked ready only after its engine is integrated and tested. Online services require internet and provider credentials. Large offline models may need separate model downloads; they are not bundled into the initial APK unless licensing, size, and device compatibility permit. Medical features provide educational information and safety guidance, not diagnosis or prescriptions.

## Build
The Android project is built with Gradle and GitHub Actions. The APK is a deliverable only after a successful workflow build and installation test.

## Status
Project initialization in progress. No APK release is available yet.
